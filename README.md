# SystemVerilog Fundamentals

## 📌 About This Repository

This repository contains a collection of **SystemVerilog projects, coding exercises, and verification examples** covering arrays, Object-Oriented Programming (OOP) concepts, and testbench development.

It documents my learning journey in SystemVerilog through practical implementations designed to strengthen my **RTL design and functional verification skills** for VLSI engineering.

## 🎯 Objectives

- Develop a strong understanding of SystemVerilog syntax and programming concepts.
- Practise arrays, queues, and other SystemVerilog data structures.
- Explore OOP concepts, including encapsulation, abstraction, inheritance, and polymorphism.
- Develop and understand SystemVerilog testbenches.
- Build a foundation in functional verification and advanced verification methodologies.

## 📂 Repository Contents

The repository covers the following areas:

- **Arrays and Data Structures** — Arrays, queues, and related operations.
- **Object-Oriented Programming** — Classes, objects, inheritance, encapsulation, abstraction, and polymorphism.
- **Testbench Development** — Writing testbenches to verify digital designs.
- **SystemVerilog Exercises** — Practical coding examples and programming challenges.
- **Functional Verification** — Developing verification skills for digital hardware systems.
